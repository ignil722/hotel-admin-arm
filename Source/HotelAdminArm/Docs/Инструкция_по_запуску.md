# Инструкция по запуску проекта в Visual Studio

Автор курсовой работы: **Терехов С. М.**, группа **ПИНз-123**.

Проект выполнен на C# Windows Forms и открывается через файл `HotelAdminArm.sln`.
В приложении используется фирменное оформление гостиницы `Volga Grand Hotel`.

## Требования

- Windows 10/11.
- Visual Studio с компонентом `.NET Desktop Development`.
- .NET SDK 8.0 или новее.

## Запуск

1. Откройте Visual Studio.
2. Выберите `Open a project or solution`.
3. Откройте файл `HotelAdminArm.sln`.
4. Дождитесь восстановления NuGet-пакетов.
5. Если Visual Studio спросит стартовый проект, выберите `HotelAdminArm`.
6. Нажмите `F5` или кнопку `Start`.

## База данных

При первом запуске программа автоматически создаёт SQLite-базу:

`%LOCALAPPDATA%\HotelAdminArm\hotel.db`

В базу сразу заносится демонстрационный набор данных: номера, гости, бронирования, проживания, услуги, оплаты, архив и журнал действий. Если нужно заново получить чистую демонстрационную базу, закройте программу и удалите файл `hotel.db`; при следующем запуске он будет создан повторно.

При запуске существующей базы приложение автоматически обновляет дизайн-версию: записывает название гостиницы, обновляет изображения номеров в поле `Rooms.Photo` и сохраняет версию оформления в таблице `AppSettings`.

## Что можно проверить

- Вкладка `Номера`: добавление, изменение и удаление номеров, хранение изображения номера в БД.
- В каждом номере уже есть изображение в базе данных; его можно заменить кнопкой `Выбрать фото`.
- Вкладка `Гости`: карточки регистрации гостей.
- Вкладка `Бронирование`: поиск свободного номера на даты и оформление брони.
- Вкладка `Заселение и архив`: заселение по брони или без брони, выезд и перенос данных в архив.
- Вкладка `Услуги`: добавление и редактирование дополнительных услуг.
- Вкладка `Оплата`: оплата одного или нескольких номеров одним клиентом.
